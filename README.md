# Proyecto Final - Análisis de Datos AFA 2015-2022

## Descripción del Proyecto
Este proyecto tiene como objetivo analizar datos del fútbol argentino (AFA) entre 2015 y 2022, utilizando técnicas de **análisis estadístico** y **aprendizaje automático** para responder a tres hipótesis principales.

##  Hipótesis Analizadas
1. **¿Los equipos locales marcan más goles que los visitantes?**
2. **¿El valor de mercado tiene relación con los goles anotados?**
3. **¿Las variables físicas influyen en el rendimiento del equipo?**

##  Metodología
El análisis se desarrolló en *Google Colab* empleando las siguientes etapas:

1. **Importación y limpieza del dataset**
   - Dataset: `afa_2015_2022_spa.csv`
   - Identificación automática de columnas relevantes (equipos, goles, valor de mercado, variables físicas).
2. **Hipótesis 1: Análisis de goles locales vs visitantes**
3. **Hipótesis 2: Relación entre valor de mercado y goles**
4. **Hipótesis 3: Variables físicas y rendimiento**

   
##  Resultados Principales
- **Hipótesis 1:** Confirmada. Los equipos locales marcan más goles (p < 0.001).
- **Hipótesis 2:** Correlación débil pero significativa entre valor de mercado y goles.
- **Hipótesis 3:** Las variables físicas y de mercado explican parcialmente el rendimiento (R² ≈ 0.10).
